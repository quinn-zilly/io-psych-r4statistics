# 01 — Project Archive

Anonymized R Markdown files and datasets from past student dissertation projects. Each project folder follows a standard structure so files are easy to navigate and reuse.

---

## Folder Structure

Each contributed project lives in its own subfolder:

```
01_project-archive/your-project-name/
├── README.md          # Brief description: research question, methods, packages
├── analysis.Rmd       # Main analysis file (anonymized)
├── data/              # Dataset(s), only if IRB permits sharing
└── output/            # Rendered HTML or PDF (optional)
```

A blank template is available in [`template/`](template/) — copy it as a starting point when contributing your own project.

## Contributing Your Project

After your dissertation defense, consider adding your anonymized analysis files. Your future cohort will thank you.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for step-by-step instructions — no prior Git experience needed. There are two paths: a simple browser upload on GitHub, or a full Git workflow if you want to learn it.

Before submitting, run through the **anonymization checklist** in the contributing guide to make sure no participant data or identifying file paths remain in your files.
